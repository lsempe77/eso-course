# Access & delivery

**The handbook (this site) is public.** It is published with GitHub Pages and built from
public/published material, so anyone with the link can read it. There is no login on the
handbook itself, and that is intentional — it keeps everything simple.

**Coursework is restricted to 3ie, through Google Classroom.** Exercises, submissions,
grades, and participant identity live in a Google Classroom class on 3ie's Google
Workspace. Only people with an `@3ieimpact.org` Google account can join, so the
*coursework* is automatically limited to 3ie staff — no extra tool, gateway, or login to
maintain.

## Set-up
1. In Google Classroom (signed in with your 3ie account), create a class for the programme.
2. Add the handbook: **Classwork → Create → Material** → paste the GitHub Pages URL.
3. Turn each lesson's "Try it yourself" into a **Classroom assignment**; learners submit a
   file or a link to their own work, and you track progress and give feedback there.
4. Invite colleagues (or share the class code). Your Google admin controls domain
   restriction; keep membership to 3ie.

> Note: earlier drafts gated the whole site with Cloudflare Access. That is no longer
> used — the handbook is public, and Google Classroom provides the 3ie-only layer for
> coursework.
